# Fuzzy Set Studio v0.1.0

Первая рабочая версия приложения для работы с нечёткими множествами и нечёткими отношениями.

### Возможности
- Создание и редактирование нечётких множеств.
- Выполнение операций над нечёткими множествами.
- Создание и редактирование нечётких отношений.
- Вычисление образов и прообразов нечётких множеств.
- Вычисление композиции нечётких отношений.
- Визуализация результатов вычислений.

### Стек технологий
- Java
- Spring Boot
- Vue 3
- JavaScript
- Bootstrap
- Axios

Это первая рабочая версия проекта. Дальнейшее развитие и расширение функциональности запланированы.
